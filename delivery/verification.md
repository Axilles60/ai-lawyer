# Проверки финального выпуска, 16.11.2026

Пять офлайн E2E-проверок пройдены: solution.py на новой вымышленной базе без
предрасчетов (2/2 ответов), полный файл при HTTP503, FastAPI lifecycle, история
чата и точные смещения источника. API имитируется локальным HTTP-сервером.
Проверки происхождения чанков и состава архива также пройдены.
Алгоритмы PRF и lean-header совпали по AST с измеренными историческими версиями.

Исторические оценки пяти профилей и знаменатели: results/final-selection-20261116.md.
Эти измерения относятся к историческому коду; исправления безопасности и происхождения
изменяют финальные хэши. Холодная живая проверка нового выбранного ядра на E2 (56)
и демо (18), с обычным попарным судьей, выполняется отдельно. Итоговые измерения,
лимит расходов и SHA256 архивов фиксируются в manifest и отчете GitHub Release.
Локальный судья не является оценкой закрытого набора. Платформенный прогон
полного solution.py на неизвестном числе вопросов отдельно не измерялся.

Docker и Compose отсутствуют на машине подготовки: сборка контейнера фактически
не проверялась. Dockerfile/compose и минимальные зависимости включены; проверен
пакетный Python-путь и настоящий FastAPI lifecycle в имеющемся окружении.
Скриншоты презентации показывают реальный интерфейс в запасном режиме без API.

GitHub main должен соответствовать основному архиву по Python-коду и config.py. Проверяется побайтово для каждого Python-файла ZIP.
requirements.txt сабмита содержит подмножество тех же закрепленных версий;
репозиторий дополнительно содержит зависимости веб-сервера.
В комплекте нет секретов, сырой базы организаторов или готовых поисковых индексов.


Сбой инфраструктуры оценки: на 8 потоках полная сериализация observations получила
MemoryError после 39 сохраненных ответов (531 попытка, верхняя сумма $0,53781592128,
384,454 с). Выбранный Python-код не менялся. Продолжение читает 39 сохраненных
ответов, генерирует только отсутствующие и демо на 2 потоках, без полного observer.
Суммарный расход и показатели публикуются в итоговом отчете. Это не непрерывный
замер времени и не доказательство отсутствия риска памяти на платформе.
