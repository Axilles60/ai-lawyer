# Скриншоты интерфейса

`live-chat.png` и `live-source.png` сняты 16.11.2026 из настоящего браузера на
http://127.0.0.1:8767. Использованы реальные модели организаторов и фактическая
база из 21 документа. Два запроса вернули HTTP200 без запасного ответа;
цитата выделена и прокручена в видимую область. Ответ и источник не дорисовывались.
Эти снимки используются в обновлённой презентации. В PDF фрагменты обрезаны
для читаемости, исходные PNG приложены полностью.

`chat.png` и `source.png` — более ранние снимки запасного режима на порту 8766
с отключёнными API. Они сохранены как исторические примеры деградации и не
выдаются за работу генеративной модели. Скриншоты не подтверждают качество на
всех вопросах или запуск реальных моделей внутри контейнера.
