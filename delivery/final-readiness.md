## Проверки, которые нельзя подменять

| Проверка | Что она подтверждает | Чего не подтверждает |
|---|---|---|
| Побайтное сравнение runtime | Выбранный бот-архив соответствует ядру GitHub | Успешную отправку на платформу |
| Тесты на другой вымышленной базе с имитацией API | Переносимость входа, CSV, веб-маршруты, обработку сбоя | Качество реальных моделей и Docker-запуск |
| Локальная оценка реальных моделей | Качество на указанной выборке с ошибками и знаменателями | Private-балл и время всего платформенного процесса |
| Реальные снимки резервного веб-режима | Интерфейс и переход к источнику при сбое API | Полный живой генеративный сценарий |
| Наличие Docker-файлов | Подготовленный способ запуска | Успешную сборку и запуск контейнера |
| Публикация GitHub Release | Доступность файлов по публичным ссылкам | Финальную сдачу PDF/ZIP организаторам |
