# Работа с финальным проектом
Прочитать README.md, SPEC.md и delivery/verification.md. Этот репозиторий -
продуктовый экспорт одного из пяти финальных сабмитов; локальная исследовательская
история сохранена отдельно. Сначала описывать изменение поведения в SPEC.md,
затем менять код и проверять. Не включать эксперименты без проверки, не добавлять
факты базы в код, не публиковать .env, не устанавливать зависимости автоматически.
Платные вызовы требуют явного бюджета. Сабмиты на платформу отправляет пользователь.
